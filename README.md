# NBA Analytics | by TAP

Historical & Modern NBA Statistical Dashboard with bilingual PT-BR / EN-US interface, era comparisons, player/team rankings, shooting zones, fouls/PBP, a statistical glossary, and the **Best Team Forever** matchup study.

## Live site

After GitHub Pages is enabled for `main / (root)`, the public URL will be:

**https://thalesandradepereira.github.io/nba-analytics/**

## Statistical integrity

- Missing historical metrics remain unavailable (`N/D` / `N/A`).
- No arbitrary values are imputed.
- Source values and derived metrics are kept conceptually separate.
- Shot-location, dunks, corner 3 and detailed play-by-play are source-dependent and generally available from 1996-97 onward.
- The **Best Team Forever** verdict is an analytical matchup inference, not an observed game result.

## Data source

Primary historical source used by the automated pipeline:

- `sumitrodatta/bball-reference-datasets`, based on Basketball-Reference data.

## Automatic refresh

The workflow `.github/workflows/update-nba-data.yml` runs:

- automatically on **February 11** and **August 11** every year;
- manually through **Actions → Refresh NBA Analytics data → Run workflow**;
- automatically when the data pipeline itself is changed.

The refresh pipeline:

1. downloads the source CSV tables;
2. filters/validates NBA records;
3. keeps aggregate player-season rows for traded players;
4. rebuilds player-era, team-season and league-season datasets;
5. leaves unavailable historical statistics as null;
6. writes compact JSON files under `data/`;
7. commits changed data back to the repository.
